## Evaluation periods

A private forecast's 2026 Brier cannot be compared as a like-for-like result with unrelated 2023, 2024 or 2025 leaderboards. Annual claims require the same year's scoring population, metric definition, forecast timing and documented reference. This release includes a supported **retrospective 2026 numerical comparison**; it makes no claim of winning four annual competitions.

## Public reproduction levels

1. **Fully executable examples:** synthetic forecasts, metrics, failure contracts and interactive bracket calculations.
2. **Reproducible aggregate checks:** score comparison arithmetic, receipt consistency and publication hashes.
3. **Inspectable public framework:** tests, locked environment, source code and executed review notebooks.
4. **Private research replay:** retained data, fitted models, forecast rows and exact composition rules; intentionally outside this publication.

The archive hash in a public receipt is a provenance reference. The archive itself stays private. A reviewer can rerun the public checks without acquiring it. [Disclosure](../portfolio/DISCLOSURE.md)
