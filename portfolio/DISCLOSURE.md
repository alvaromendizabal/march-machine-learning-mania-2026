## Scope of this update

This publication contains a revised entry-point README, an experiment ledger, equal-season aggregates of selected user-supplied results, and their provenance. No research fit or project notebook was executed to produce this update. The aggregation is a presentation calculation over existing reported metrics, not a new experiment.

## Existing public source

The repository already contains the earlier MIT-licensed implementation, executed canonical notebooks, and released scientific evidence. Those files and their Git history are not removed or relicensed by this update. This portfolio directory must not be interpreted as a claim that the entire repository is source-free or technically uncopyable.
