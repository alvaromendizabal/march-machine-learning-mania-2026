# Source lineage

`frozen/research_workflow.py` and `frozen/shot_features.py` are preserved from the
previous supplied kit. `frozen/consensus_reference.py` is the previous
`consensus_features.py`, under a distinct module name; the bytes are unchanged.
`research_io.py` is the previous helper, with byte identity retained. Each is checked
by `constraints.json` or the package manifest before project computation.

The reviewed reference repository is:
https://github.com/alvaromendizabal/march-machine-learning-mania-2026/tree/84b8fb36644a6558beded6dad84f5645ea4405d3

This kit has not been committed, pushed, merged, deployed or submitted. It reads the
existing workspace only when the user runs it. It does not require additional cloud
resources, external data downloads, credentials in notebooks, or a Git connection.
Scientific sources are linked in each protocol. New formula choices are explicitly
identified as hypotheses, not attributed to sources that did not test them.

Raw data and private model caches are not bundled. The included evidence consists of
aggregate user-supplied reports; their original report-integrity manifest is retained.
New experiment outputs are stored privately under fingerprinted run directories until
manually selected for future publication. Synthetic validation outputs are not shipped
as real project metrics or pre-executed competition results.
